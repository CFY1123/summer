# AI 学习助手需求规约

## 1. 项目目标

开发一套基于 LangChain 的智能学习辅助系统，实现从知识库构建、学习路径规划、自动测评、学习进度追踪到安全登录与语音交互的闭环原型。

前端引用地球OL初级玩家的 `Earth-OL-Player/ai_learn_project.git` 项目中的 `ai-learn-web`，后端改为本项目自建的 Python + FastAPI 服务。

## 2. 本阶段功能

### 2.1 本地知识库构建

- 支持上传 PDF、DOCX、TXT 三类常见课程资料。
- 上传后解析文本，按章节或固定长度分块。
- 使用 Chroma 作为本地向量数据库，结合 LangChain 建立检索索引。
- 支持知识库查看、删除、追加文档，更新后同步刷新索引。

### 2.2 课程大纲与章节学习

- 基于知识库内容自动生成章、节两级课程大纲。
- 用户选择章节后，生成该章节学习总结和要点。
- 持久化记录章节进度：未开始、学习中、已完成。
- 提供进度看板、完成百分比、进度重置和手动标记。

### 2.3 在线测验与错题复盘

- 每章自动生成不少于 5 道客观题，支持选择题和判断题。
- 支持按章节、难度随机抽题，并配置答题时间。
- 自动批改，返回得分、正确答案和简要解析。
- 保存考试历史：分数、用时、错题明细。
- 自动归档错题，支持按章节或难度重练，并统计正确率变化。

## 3. 人脸识别登录

- 支持用户通过摄像头采集人脸模板并完成注册。
- 登录时再次采集摄像头画面并与本地模板比对，未注册或匹配失败时拒绝访问。
- 通过两帧画面差异实现简单活体检测，降低静态照片通过概率。
- 人脸识别失败时显示明确提示，并保留密码登录作为备用方式。

## 4. 语音交互模式

- 支持通过“打开学习”“开始测验”“查看进度”等语音指令跳转主要功能。
- 支持使用浏览器语音合成播报操作结果。
- 提供语音输入开启/关闭开关；不支持语音识别的浏览器会提示用户继续使用按钮操作。

## 5. 技术选型

- 前端：Vue 3 + TypeScript + Vite + Element Plus。
- 后端：Python + FastAPI。
- LLM 编排：LangChain。
- 向量数据库：Chroma，本地持久化到 `backend-python/storage/chroma`。
- 业务数据库：本地 MySQL，库名 `learning_platform`。
- 文档解析：pypdf、python-docx、TXT 原生读取。
