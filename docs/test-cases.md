# 商品管理模块测试用例

## 1. 测试范围

测试覆盖商品管理模块的页面展示、筛选查询、商品新增编辑、状态流转、库存管理、批量操作、Excel 导入导出、统计看板、异常提示和核心后端业务逻辑。

## 2. 测试环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows 11 开发环境，Linux 部署环境 |
| 前端 | Vue 3、Element Plus、axios、Pinia、TypeScript |
| 后端 | Spring Boot、MyBatis、MySQL |
| 数据库 | MySQL 8.x，端口 3306，root/123456 |
| 浏览器 | Chrome、Edge |

## 4. 接口测试用例

| 编号 | 接口 | 方法 | 重点校验 |
| --- | --- | --- | --- |
| API-001 | /api/goods | GET | 分页参数、筛选条件、返回 total 和 records |
| API-002 | /api/goods/stats | GET | total、onSale、pending、stockWarning 数值 |
| API-003 | /api/goods | POST | 必填校验、SPU 唯一校验、默认待审核 |
| API-004 | /api/goods/{id} | PUT | 商品字段更新、已下架商品转待审核 |
| API-005 | /api/goods/{id}/status | PATCH | 单条状态修改 |
| API-006 | /api/goods/status | PATCH | 批量状态修改 |
| API-007 | /api/goods/{id}/stock | PATCH | 单条库存修改 |
| API-008 | /api/goods/stock | PATCH | 批量库存修改 |
| API-009 | /api/goods/{id} | DELETE | 单条逻辑删除 |
| API-010 | /api/goods | DELETE | 批量逻辑删除 |
| API-011 | /api/goods/import-template | GET | 返回 Excel 模板文件 |
| API-012 | /api/goods/import | POST | 文件类型校验、行级错误返回 |
| API-013 | /api/goods/export | GET | 返回 Excel 商品数据 |
| API-014 | /api/categories | GET | 返回启用分类下拉数据 |

## 5. 自动化测试

后端已编写 `GoodsServiceTest`，覆盖：

- 新增商品默认待审核；
- SPU 重复校验；
- 已下架商品编辑后转待审核；
- 单条状态修改；
- 单条库存修改；
- 批量状态、库存、删除调用。

执行命令：

```bash
cd backend
mvn test
```
